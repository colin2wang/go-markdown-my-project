# GUI 设计文档 — Project Docs GUI
> 承接《开发文档》§8，本文档将 GUI 部分展开为可直接实现的设计规格：信息架构、页面线框图、组件 Props、交互状态机、视觉规范、边界状态。技术栈沿用 Vue 3 + TS + Pinia + Naive UI + Wails。
---
## 1. 设计原则
| 原则 | 落地方式 |
|---|---|
| **工作台优先** | 用户会反复调整文件范围后导出，因此导出流程不做"分步向导"，改为单页工作台（左树右参），减少来回切换 |
| **所见即所导** | 右侧实时预览最终 Markdown 的大纲结构与脱敏命中，导出前可确认 |
| **危险操作显性化** | 敏感信息采用"先扫描→人工确认→再导出"两阶段流，绝不静默替换 |
| **反馈即时** | 任何 >200ms 的操作（扫描/估算/导出）必须有 loading 态或进度事件 |
| **桌面原生感** | 跟随系统深/浅色主题；记住窗口布局与侧栏折叠状态；提供快捷键 |
---
## 2. 信息架构与导航
```
App
├── Sidebar（固定左侧 200px，可折叠为 64px 图标栏）
│   ├── 工作台          ← 默认页，徽标：无
│   ├── 项目管理
│   ├── 敏感报告        ← 徽标：最近一次扫描的命中数（如 3）
│   ├── 历史
│   └── 设置
├── Content（路由视图）
└── StatusBar（底部 28px）
    ├── 左：后端状态（● 已就绪 / 正在扫描 epub_reader…）
    ├── 中：最近导出结果（上次的输出路径，点击打开）
    └── 右：版本号 + 主题切换 🌓
```
窗口约束：最小尺寸 `1100 × 720`，默认 `1440 × 900`；布局偏好（侧栏折叠、列宽、主题）持久化到 `localStorage`。

## 3. 页面详细设计
### 3.1 工作台（核心页，路由 `/workbench`）
三栏布局 + 底部操作条：

#### ① 项目选择条
- 下拉框列出 `ListProjects()` 全部项目，支持拼音/名称过滤；选中即加载配置并自动扫描。
- `重新扫描`：重跑 `ScanProject`，文件树、勾选状态、估算全部刷新（勾选状态按相对路径尽量保留）。
- `编辑配置`：打开抽屉表单（同项目管理页复用组件）。
- 多项目合并导出（F1 的"所有项目"）：下拉框末尾有 `＋ 多选模式…`，进入多选弹层，勾选 ≥2 个项目后，文件树按项目分组显示，导出时各项目章节拼接，项目名之间插入 `---` 分隔线。
#### A. 文件树面板（宽 300px，可拖拽调宽）
- 树节点 = 配置中 `files + directories` 合并扫描结果（`ScanProject` 返回）。
- 每个文件节点显示：语言图标 + 文件名 + 右侧灰色徽标（`≈1.2k` tokens）。
- 目录节点三态勾选（全选/半选/未选）；父级勾选 = 子级全选；取消子项时父级变半选。
- 顶部工具行：搜索框（按文件名过滤，命中高亮并展开路径）、`全选/全不选`、`仅选代码文件`（按 `langs.yml` 中的语言过滤）、`反选`。
- 底部统计：`已选 x/y 文件` + `≈N tokens`（勾选变化即实时调 `Estimate`，300ms 防抖）。
- 虚拟滚动（Naive UI `n-tree` 的 `virtual-scroll`），支持 5000+ 节点。
- 右键菜单：`在资源管理器中打开` / `预览此文件`（在 C 面板原文 Tab 显示前 200 行）。
#### B. 选项面板（宽 320px）
**导出模式**（单选卡片组，5 张卡，每卡：图标 + 标题 + 一句描述）：
| 卡片 | 标题 | 描述 | 对应 |
|---|---|---|---|
| 📄 | 完整代码 | 文件树 + 全部文件内容 | F1 |
| 🗂 | 文件名清单 | 仅文件树与路径列表 | F2 |
| 🔎 | 符号目录 | 文件名 + 方法/类名列表（启发式） | F3 |
| ✍️ | 签名导出 | 文件名 + 完整函数签名 | F4 |
| 🧩 | 自定义模板 | 按模板文件渲染 | F4 |
选中 `符号目录/签名导出` 时，卡片下方出现淡色提示条：`基于启发式解析，可能存在漏报`。
**敏感过滤**：
- 开关 `导出时自动剔除密码/密钥`（默认开，记住上次状态）。
- 策略下拉：`占位符替换` / `删除整行`；`替换文本` 输入框（仅占位符模式显示）。
- 按钮 `扫描敏感信息` → loading → 完成后显示结果芯片：
   - `✓ 未发现敏感信息`（绿色）
   - `⚠ 发现 3 处 → 查看`（橙色，点击跳转 C 面板"敏感"Tab 或敏感报告页）
- 自定义正则入口：`＋ 添加规则`，弹窗输入名称 + RE2 正则，实时校验（编译失败红框提示错误信息）。
  **Token 分片**：数字输入框 + 单位提示（`0 = 不分片`）；>0 且预估超限时显示 `预计切成 2 片`。
  **输出**：输出文件名（默认读配置 `output_file`）+ 输出目录（默认 `output/`，有 `浏览…` 按钮）。
#### C. 输出预览（弹性宽度）
三个 Tab：
1. **大纲**：渲染最终 Markdown 的标题层级（H1/H2/H3 树状缩进列表），点击标题滚动/查看章节文件数。这是"所见即所导"的主视图——用户能提前看到"将产出哪些章节、每个文件下会列出哪些符号"。
2. **敏感命中**：本页内嵌精简版命中表（文件 | 行 | 类型 | 掩码预览），行尾按钮 `标为误报`。顶部链接 `查看完整报告 →`。
3. **原文**：任选一个已勾选文件，显示前 200 行（等宽字体、行号、按语言高亮），用于确认该文件是否该进导出。
   预览数据来自 `Estimate`（大纲）与 `ScanSecrets`（敏感），不做完整 markdown 渲染（避免大文档卡顿），`预览全部` 按钮才生成完整产物到临时窗口打开。
#### ③ 底部操作条
- 左侧实时摘要：`12 文件 · 214 KB · ≈82,000 tokens · 脱敏 3 处`。
- 右侧按钮：
   - `预览`（次按钮）：生成完整 Markdown 存临时文件并打开。
   - `导出 ▸`（主按钮）：点击后展开**导出确认弹层**（见 §5.1），确认后才执行。
- 导出过程中此条变为进度条模式：`正在导出 45% ─ 读取 lib/parser.dart`，完成后变绿色 `✓ 已导出 → epub_reader.md [打开文件] [复制全部] [查看历史]`。

### 3.3 敏感报告页（`/secrets`）
```
┌──────────────────────────────────────────────────────────────┐
│ 敏感信息报告        项目[全部 ▾] 类型[全部▾] [已确认|误报|全部]  │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 文件           行   类型      规则           掩码预览   操作 │ │
│ │ lib/auth.dart  42  password  generic-assign  sk-abc…​***Xy  │ │
│ │                    │                            [✓敏感][🚫误报]│ │
│ │ config.yml     8   db_url    conn-string    mysql://***   │ │
│ │ main.dart      15  api_key   openai-style   sk-****…​      │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 汇总: password 1 · api_key 1 · db_url 1    [批量标为误报]      │
└──────────────────────────────────────────────────────────────┘
```
- 点击行展开：显示命中行**上下文 ±3 行**（敏感值部分以橙色块遮罩，hover 显示掩码预览），确保用户能判断是否真敏感。
- `🚫 误报` → 写入配置 `redaction.allowlist`，行变灰划线，可撤销。
- 掩码规则（与后端一致）：保留前 4 后 2 字符，中间 `*`；短于 8 字符全遮罩。
- 空状态：`未扫描过 / 未发现敏感信息`，附"如何工作"说明卡片（规则来源、误报机制）。
### 3.4 历史页（`/history`）
表格列：时间 | 项目 | 模式 | 输出文件 | ≈Tokens | 脱敏数 | 耗时 | 操作（打开文件 / 重新导出 / 复制路径）。
- `重新导出`：以该历史条目的完整参数预填工作台。
- 数据源 `GetHistory()`；顶部搜索按项目名过滤；最多保留 200 条，超出提示清理。
### 3.5 设置页（`/settings`）
分组表单：
- **通用**：默认输出目录、界面语言（zh/en）、主题（跟随系统/浅/深）。
- **扫描**：全局排除目录（追加到每个项目）、默认大小上限。
- **敏感过滤**：全局自定义正则管理（表格 CRUD，同 3.1 弹窗组件复用）、默认策略、默认替换文本。
- **日志**：`打开日志目录` 按钮、日志级别下拉（写回 logger.yml）。

### 4.1 FileTreeCheckable
```ts
interface TreeNode {
  path: string            // 相对路径，统一 '/'
  name: string
  type: 'file' | 'dir'
  language?: string       // langs.yml 映射
  sizeBytes?: number
  estTokens?: number      // 无值为 0，不显示徽标
  children?: TreeNode[]
}
// Props
{ nodes: TreeNode[]; checked: Set<string>; loading?: boolean }
// Emits
{ 'update:checked': Set<string> }   // v-model:checked
{ 'preview': string }               // 右键预览，relPath
```

## 5. 关键交互流程（状态机）
### 5.1 导出流程（含确认弹层）
```
[idle] --选项目--> [scanning] --ScanProject完成--> [ready]
   ▲                  │失败: 错误横幅 + 重试
   │                                                   
[ready] --点[导出]--> [confirm 弹层]                     
   弹层内容：                                           
   ┌────────────────────────────────────┐              
   │ 导出确认                            │              
   │ 项目: EPUB Reader（完整代码模式）      │              
   │ 12 文件 · ≈82,000 tokens · 不分片    │              
   │ 敏感过滤: 开启（占位符 [REDACTED]）    │              
   │ ⚠ 尚未扫描敏感信息，[立即扫描] 或 [跳过]│              
   │          [取消]  [确认导出]          │              
   └────────────────────────────────────┘              
   --确认--> [exporting] --export:done--> [done ✓]      
                     │export:error--> [error → 重试]     
```
**规则**：`redact` 开启但从未执行过 `ScanSecrets`（或扫描后文件集变了）时，确认弹层强制出现黄色警告与 `立即扫描` 按钮——这是 F99"不静默"原则在 UI 的兜底。
### 5.2 敏感确认流
```
工作台[扫描敏感信息] ──→ loading ──→ 结果芯片
                                      ├─ 0 处: 绿色，直接可导出
                                      └─ N 处: 橙色 → C面板敏感Tab / 报告页
逐条判定: [✓敏感](默认，导出时替换) / [🚫误报](写allowlist，导出时保留)
```

## 7. 视觉规范
| 项 | 规格 |
|---|---|
| 主题 | Naive UI `darkTheme`/默认，跟随 `prefers-color-scheme`，可手动覆盖 |
| 主色 | 蓝 `#2080f0`（操作按钮/进度条）；敏感/警告橙 `#f0a020`；成功绿 `#18a058`；错误红 `#d03050` |
| 字体 | 界面 `system-ui 14px`；代码/路径/掩码 `JetBrains Mono / Consolas 13px`；中文回退 `PingFang SC, Microsoft YaHei` |
| 间距 | 8px 栅格；面板内边距 16px；卡片间距 12px |
| 密度 | 表格/树用 compact 尺寸（`size="small"`） |
| 徽标 | token 数灰色小徽标；命中数橙色圆点徽标（侧栏敏感入口） |
| 图标 | `@vicons/ionicons5`，语言图标按 `langs.yml` 映射彩色小圆标 |
| 空状态 | Naive UI `n-empty` + 一句引导文案 + 主操作按钮 |
| 加载 | 树/表格用骨架屏（`n-skeleton`）；按钮内 spinner；禁止整页白屏 loading |

| 快捷键 | 动作 |
|---|---|
| `Ctrl/Cmd + P` | 工作台项目下拉聚焦 |
| `Ctrl/Cmd + F` | 文件树搜索聚焦 |
| `Ctrl/Cmd + S` | 扫描敏感信息 |
| `Ctrl/Cmd + E` | 导出（=点导出按钮） |
| `F5` | 重新扫描文件树 |
| `Ctrl/Cmd + 1..5` | 切换侧栏页面 |
| `Esc` | 关闭弹层/抽屉 |

## 9. 边界与异常状态清单
| 场景 | 表现 |
|---|---|
| 无任何项目配置 | 工作台整页空状态：`还没有项目配置 → [创建第一个项目]` |
| 项目路径失效（目录被删） | 项目选择条红条警告：`路径不存在: xxx [重新选择]`，禁用导出 |
| 扫描 0 文件 | 树面板空态 + 提示检查 include 配置 |
| 估算 >100 万 tokens | 底部摘要变橙 + 建议开启分片的 toast |
| 单文件超分片上限 | Estimate 返回警告字段，预览 Tab 顶部黄条说明该文件将独占一片 |
| 自定义正则编译失败 | 弹窗内即时红框 + RE2 错误信息，禁止保存 |
| 导出写盘失败（权限/占用） | error 态 + 失败原因 + `打开输出目录` 按钮 |
| 敏感扫描后用户改了勾选 | `scanDirty=true`，敏感芯片变灰 `已过期，重新扫描`，确认弹层重新要求扫描 |
