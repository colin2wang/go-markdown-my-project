# Wails v2 → v3.1.0 升级计划（go-markdown-my-project）
## 一、现状分析：代码中的 Wails v2 触点清单
对现有代码逐文件排查，Wails v2 的耦合集中在 **4 处**，其余 core/ 包完全无 Wails 依赖（这是本次升级的最大利好）：
| 文件 | v2 用法 | 升级动作 |
|---|---|---|
| `app/app.go` | `import ".../wails/v2/pkg/runtime"`；`App.ctx` 字段；`Startup(ctx)`（内含 `defer runtime.WindowShow`、`runtime.EventsEmit("app:log")`）；`SelectDirectory`/`SelectFiles` 用 `runtime.OpenDirectoryDialog` / `OpenMultipleFilesDialog` | **重构**：改写为 v3 Service，运行时调用全部替换 |
| `app/version.go` | 无 Wails 依赖，仅靠 `build.ps1` 编译期 `-ldflags -X` 注入 `BuildVersion` | 代码不变；**build 脚本改从 Taskfile 变量注入** |
| `app/openpath_windows.go` / `openpath_other.go` | 纯 Go（COM/Shell），无 Wails 依赖 | 不动 |
| `frontend/wailsjs/**`（`go/models.ts`、`go/app/App.js|.d.ts`、`runtime/runtime.js`） | v2 生成物 | **删除**，改用 `wails3 generate bindings` 生成到 `frontend/bindings/`，JS 侧换 `@wailsio/runtime` |
| 根目录（文件树未列出但必须存在）：`main.go`、`go.mod`、`wails.json`、`build.ps1` | `wails.Run(&options.App{... StartHidden, Bind})`；`wails/v2` 依赖；v2 构建流程 | **重写 main.go**；go.mod 换 v3；wails.json 换 v3 格式；build.ps1 重写 |
| `tools/genicon/`（svg→ico/png 自研工具） | 自研图标生成链路 | 保留 svg→appicon.png 职责，**平台图标改用 `wails3 generate icons` + `wails3 generate syso`** |
core/ 下的 15 个包（scanner、generator、token、redactor、wordfilter、compress、symbol、pick、infer、gitignore、i18n、config、logger…）**零改动**，相关单元测试（含 golden 快照）不受影响。
## 二、v2 → v3 API 对照表（本项目实际用到的）
| v2 | v3.1.0 |
|---|---|
| `wails.Run(&options.App{Bind: [...]})` | `application.New(application.Options{Services: [...]})` + `app.Run()` |
| `a.startup(ctx)` + `ctx` 字段 | `ServiceStartup(ctx, application.ServiceOptions) error`，app/window 以显式字段注入 |
| `runtime.WindowShow(ctx)`（配合 StartHidden） | 创建窗口时 `Hidden: true`，就绪后 `win.Show()` |
| `runtime.EventsEmit(ctx, "app:log", e)` | `app.Event.Emit("app:log", e)` |
| `runtime.OpenDirectoryDialog(ctx, opts)` | `app.Dialog.OpenFile().SetTitle(...).CanChooseDirectories(true).CanChooseFiles(false).PromptForSingleSelection()` |
| `runtime.OpenMultipleFilesDialog(ctx, opts)` | `app.Dialog.OpenFile()...PromptForMultipleSelection()` |
| `OpenDialogOptions{Title, DefaultDirectory}` | 链式 `SetTitle(...)` / `SetDirectory(...)` |
| `wailsjs/go/app/App` 导入 | `bindings/<module>/<pkg>` 导入（由生成器产出，路径以实际输出为准） |
| `wailsjs/runtime/runtime`（JS） | npm 包 `@wailsio/runtime` 的 `Events.On` |
| `wails dev` / `wails build` | `wails3 dev` / `wails3 build`（= `wails3 task build` 别名） |
| 输出在 `build/bin/` | 输出在 **`bin/`** |
| 构建期自动嵌图标 | Taskfile 中 `generate:icons` + `generate:syso` 显式任务 |
> 版本说明：`v3.1.0` 写作时若正式 tag 尚未发布（仅见 `v3.1.0-nightly.20261028`），命令中的 `@v3.1.0` 以实际存在的最近 tag 替换；`wails3 version` 确认。v2/v3 CLI 与 import path 独立，可并存回滚。
## 三、实施步骤
### Phase 0 环境准备
```bash
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.1.0
wails3 doctor        # 环境自检
git checkout -b feat/wails3
```
同时确认 Go 版本满足 v3 要求（文档示例 go 1.25，必要时上浮 go.mod 的 go 指令）。
### Phase 1 Go 后端
**1) go.mod**
```
go get github.com/wailsapp/wails/v3@v3.1.0
go mod tidy      # v2 依赖会被移除
```
**2) 重写 `main.go`**（对齐原 `StartHidden` + AssetServer + Bind 语义）

```go
package main

import (
   "embed"
   "log"
   "github.com/wailsapp/wails/v3/pkg/application"
   "go-markdown-my-project/app"
)

//go:embed all:../../frontend/dist
var assets embed.FS

func main() {
   a := app.NewApp()
   wailsApp := application.New(application.Options{
      Name: "ProjectDocs",
      Assets: application.AssetOptions{
         Handler: application.AssetFileServerFS(assets),
      },
      Services: []application.Service{
         application.NewService(a),
      },
   })
   a.SetApplication(wailsApp) // 注入引用，供事件/对话框使用
   wailsApp.Window.NewWithOptions(application.WebviewWindowOptions{
      Name:   "main",
      Title:  "ProjectDocs",
      Width:  1280,
      Height: 800,
      Hidden: true, // 对齐原 StartHidden：ServiceStartup 完成后再显示
   })
   if err := wailsApp.Run(); err != nil {
      log.Fatal(err)
   }
}
```
> 原 main.go 里的 windows/mac 平台 options（透明、单实例等）逐项映射到 v3 对应字段；以实际旧文件为准补齐。
**3) 改造 `app/app.go`**（仅 4 个触点，其余 30+ 绑定方法签名不动）
```go
import (
	"context"
	"github.com/wailsapp/wails/v3/pkg/application"
	// 删除 "github.com/wailsapp/wails/v2/pkg/runtime"
)
type App struct {
	app *application.App      // 替代 ctx
	win *application.WebviewWindow
}
func NewApp() *App { return &App{} }
func (a *App) SetApplication(ap *application.App)      { a.app = ap }
func (a *App) SetWindow(w *application.WebviewWindow)  { a.win = w }
// Startup → ServiceStartup
func (a *App) ServiceStartup(ctx context.Context, options application.ServiceOptions) error {
	// 原 defer runtime.WindowShow(ctx) 语义：启动完成后显示窗口
	defer func() {
		if a.win != nil {
			a.win.Show()
		}
	}()
	logger.SetSink(func(e logger.Entry) {
		a.app.Event.Emit("app:log", e) // 原 runtime.EventsEmit(a.ctx, "app:log", e)
	})
	logger.Info(i18n.T("log.started"))
	return nil
}
// SelectDirectory：目录选择 = OpenFile 对话框 + CanChooseDirectories
func (a *App) SelectDirectory(startDir string) (string, error) {
	b := a.app.Dialog.OpenFile().
		SetTitle("选择目录").
		CanChooseDirectories(true).
		CanChooseFiles(false)
	if startDir != "" {
		if abs, err := filepath.Abs(startDir); err == nil {
			if info, err := os.Stat(abs); err == nil && info.IsDir() {
				b = b.SetDirectory(abs) // 原 OpenDialogOptions.DefaultDirectory
			}
		}
	}
	return b.PromptForSingleSelection() // 取消时返回 ("", nil)，语义与 v2 一致
}
// SelectFiles：多选文件
func (a *App) SelectFiles(startDir string) ([]string, error) {
	b := a.app.Dialog.OpenFile().SetTitle("选择文件")
	if startDir != "" {
		if abs, err := filepath.Abs(startDir); err == nil {
			if info, err := os.Stat(abs); err == nil && info.IsDir() {
				b = b.SetDirectory(abs)
			}
		}
	}
	return b.PromptForMultipleSelection()
}
```
`version.go` 的 `-X` 注入目标路径 `go-markdown-my-project/app.BuildVersion` 不变，`GetVersion()` 仍作为绑定方法暴露。
### Phase 2 前端
1. `frontend/package.json` 增加 `"@wailsio/runtime"`；**删除 `frontend/wailsjs/` 整个目录**。
2. 生成 v3 绑定（build 任务也会自动跑）：
   ```bash
   wails3 generate bindings -d frontend/bindings -ts -silent
   ```
3. `src/api/bindings.ts`：所有 `../../wailsjs/go/app/App` → 生成的绑定路径（形如 `../bindings/go-markdown-my-project/app/...`，以生成器实际输出为准）；models 改从 `bindings` 下的 `models.ts` 导入。
4. 事件监听改造（`stores/log.ts`、`LogPanel.vue`）：
   ```ts
   // v2: import { EventsOn } from '../../wailsjs/runtime/runtime'
   // v3:
   import { Events } from '@wailsio/runtime'
   Events.On('app:log', (ev) => {
     const entry = ev.data?.[0] ?? ev.data  // v3 载荷在事件对象上，以 dev 实测为准
   })
   ```
### Phase 3 构建系统 + build / generate-icon 脚本
**1) 脚手架 v3 构建资产**（生成 `Taskfile.yml`、`build/config.yml`、NSIS/Info.plist/.desktop 模板）：
```bash
wails3 generate build-assets
```
**2) 更新 `wails.json`**（v3 格式；本项目用 **pnpm**，命令要对应改）：
```json
{
  "name": "go-markdown-my-project",
  "frontend": {
    "dir": "./frontend",
    "install": "pnpm install",
    "build": "pnpm build",
    "dev": "pnpm dev",
    "devServerUrl": "http://localhost:5173"
  }
}
```
**3) Taskfile.yml**（在模板基础上定制：时间戳 ldflags + 图标链路；`wails3 build` 即 `wails3 task build`）：
```yaml
version: '3'
vars:
  APP_NAME: ProjectDocs
  APP_MODULE: go-markdown-my-project
  # 本地时区构建时间戳，下划线占位（与 app/version.go 约定一致，避免 ldflags 值含空格）
  BUILD_TIME:
    sh: date "+%Y-%m-%d_%H:%M:%S"
  LDFLAGS: >-
    -H=windowsgui
    -X '{{.APP_MODULE}}/app.BuildVersion={{.BUILD_TIME}}'
tasks:
  generate:appicon:
    desc: genicon 自研工具：SVG 源 → build/appicon.png（仅保留这一职责）
    cmds:
      - go run ./tools/genicon -out build/appicon.png   # 按现有 main.go 实际 flag 调整
  generate:icons:
    desc: v3 CLI：PNG → 全平台图标（ico/icns 等）
    cmds:
      - wails3 generate icons -input build/appicon.png
        -windowsfilename build/windows/icon.ico
        -macfilename build/darwin/icon.icns
      - wails3 generate syso   # Windows 资源文件：图标+清单+版本信息（flag 见 --help）
  build:
    cmds:
      - task: generate:appicon
      - task: generate:icons
      - wails3 generate bindings -d frontend/bindings -ts -silent
      - wails3 task install:frontend:deps
      - wails3 task build:frontend
      - go build -tags production,desktop -ldflags "{{.LDFLAGS}}" -o bin/{{.APP_NAME}}.exe .
  dev:
    cmds:
      - wails3 dev
```
（模板自带 `install:frontend:deps` / `build:frontend` / `common:generate:icons` 任务，可二选一：用模板任务或上述合并版。）
**4) 重写 `build.ps1`**（原来直接 `wails build` + ldflags 注入，现改为传变量给 Task）：
```powershell
# build.ps1
$ErrorActionPreference = "Stop"
wails3 doctor
$buildTime = Get-Date -Format "yyyy-MM-dd_HH:mm:ss"
wails3 task build "BUILD_TIME=$buildTime"
Write-Host "Output: bin/ProjectDocs.exe  (BuildVersion=$buildTime)"
```
**5) 新 `generate-icon` 脚本**（替代旧的「genicon 直接产 ico」流程）：
```powershell
# scripts/generate-icons.ps1
$ErrorActionPreference = "Stop"
# 1) SVG 源 → appicon.png（保留 tools/genicon 仅做源图）
go run ./tools/genicon -out build/appicon.png
# 2) v3 CLI：一份 PNG → Windows .ico / macOS .icns（flags: -input/-windowsfilename/-macfilename/-iconcomposerinput/-macassetdir）
wails3 generate icons -input build/appicon.png `
  -windowsfilename build/windows/icon.ico `
  -macfilename build/darwin/icon.icns
# 3) Windows .syso（图标+manifest+版本信息；v2 是 wails build 隐式完成，v3 显式生成）
wails3 generate syso
```

## 四、风险与回滚
| 风险 | 缓解 |
|---|---|
| `v3.1.0` 正式 tag 可能未发布（现有 nightly 为 `v3.1.0-nightly.20261028`） | 锁定实际存在的最近 tag，升级命令与文档同步 |
| 事件载荷在 v3 中为事件对象（`.data`），JS 端取值方式变化 | 迁移时以 `wails3 dev` 实测为准，只在 `stores/log.ts` 单点适配 |
| 绑定生成路径与 wailsjs 不同 | `api/bindings.ts` 是唯一聚合层，改动集中在一处 |
| 图标链路从隐式变显式 | generate-icon 脚本固化 `genicon → generate icons → generate syso` 三步，CI/本地同一入口 |
| v2 与 v3 CLI/import 并存 | 独立二进制 `wails`/`wails3`、独立模块路径；出问题切回 `main` 分支即可，无环境污染 |
